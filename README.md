# RR Automation & Web

Static portfolio website for RR Montoya.

## Publish with GitHub Pages

1. Create a public GitHub repository named `rr-automation-web`.
2. Upload `index.html` and `.nojekyll` to the root of the `main` branch, then commit.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, then **main** and **/(root)**, and save.
5. GitHub will show the published URL in Pages settings. It will normally be `https://YOUR-USERNAME.github.io/rr-automation-web/`.

Edit `index.html` and commit again to update the website.
